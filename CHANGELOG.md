# Changelog

All notable changes to this project will be documented in this file.

## [1.0.1] - 2026-05-28

### Added
- Islamic quiz with multilingual support (Arabic, Hindi, Urdu).
- Settings drawer for user preferences and backup management.
- Prayer offset adjustment functionality.
- Drag-and-drop functionality for panel layout customization.
- New components: DuaTab, QiblaTab, and HadithTab.
- Caching for API calls.
- Search engine options in settings.

### Changed
- Enhanced localization for various UI elements.
- Improved time formatting in PrayerTimesCard.
- Updated import paths to use absolute imports.
- Enhanced settings management with safer merging and broadcast updates.

### Fixed
- Removed redundant console log statements.

## [1.0.0] - 2026-03-15

### Added
- Initial release of NoorTab.
- Prayer times and Adhan reminders.
- Adhkar player and Dua library.
- Translation support for multiple languages.
- Dev mode tools and simulated location.
- Professional README and documentation.

### Fixed
- Standardized comment formatting.
- Resolved UI bugs and time simulation issues.
- Improved translation for hardcoded strings.
